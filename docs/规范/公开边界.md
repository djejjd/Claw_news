## 可以公开

- 根目录项目说明和许可证
- `.github/workflows/` 中与项目质量门禁相关的 CI 配置
- `docs/产品/`、`docs/架构/`、`docs/运维/`、`docs/计划/`、`docs/研究/`
- `docs/运维/launchd/` 下的 `.example` 模板

## 只作内部或历史材料

- `spec/`（如存在）全部内容
- `.superpowers/`、`.claude/`、`.prompt/` 等本地或内部工具目录
- 真实服务器地址、账号和私有部署脚本；公开仓库只保留脱敏模板
- `docs/归档/` 可以保留在仓库用于追溯，但不作为当前文档入口；其中的历史内容仍须脱敏。
- `docs/temp/` 临时文件
- 未脱敏的真实 plist、日志、候选数据和运行状态

## 提交前检查

公开文档不得包含真实 API key、token、webhook、cookie 或个人机器绝对路径。示例使用占位符，运行时 `.env` 和 `data/` 不入库。
