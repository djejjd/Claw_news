## 当前来源

- AI：HuggingFace Daily Papers、量子位及配置的 AI RSS。
- 工具：GitHub 项目快照和工具类 RSS。
- 游戏：TapTap 下载榜、游研社及其他游戏 RSS。
- 数码内容：IT之家、少数派等 RSS，运行时按工具类展示。

实际来源由 `collectors/ai_rss.py`、`app/ingest/source_registry.py` 和运行时 feeds 配置共同决定。

## 来源策略

每个来源可以配置层级、保留时长、质量权重、过滤档位和单次入选上限。RSS 来源写在 `feeds` 下，TapTap 等非 RSS 来源写在 `source_policies` 下；两类策略都会进入正式选材。来源失败由单源隔离逻辑记录，不应阻断其他来源。

## 新增来源

先验证可达性、更新频率、内容质量和分类归属，再加入正式配置。临时试验源放在本地配置或 `docs/研究/` 记录中，不直接写进正式来源列表。

## 已知限制

国外来源可能受网络、代理或 API 限流影响。HuggingFace 可通过 `HF_OPTIONAL=1` 降级为跳过；来源指标写入异常会记录为非阻塞错误，当前待后续治理。
