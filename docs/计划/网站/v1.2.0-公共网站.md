## 1. 目标、非目标与退出条件

目标是在独立 Vue 3 + TypeScript 应用中交付未登录用户的公共浏览体验：日报首页、最近十天新闻流、来源筛选、原文跳转，以及加载、空和失败状态；界面须在桌面和移动端可读。

非目标是登录、注册、邀请、订阅、收藏、已读、推荐、正文抓取、管理界面、API 或数据库变更、生产部署和 CORS 策略。前端不读取候选池、JSON 运行状态或模拟内容。

退出条件：真实公共 API 可支持未登录用户完成日报浏览、新闻分页和来源筛选；核心路径具备端到端验证；所有请求失败均明确呈现且不以旧数据或模拟数据伪成功。

## 3. 任务依赖与并行限制

```text
T0 前端设计冻结
  -> T1 前端工程、隔离 API E2E 与 CI 基础
    -> T2 日报首页
      -> T3 新闻流、来源筛选与外链
        -> T4 响应式与端到端验收
          -> T5 正式版本发布
```

同一 `frontend/src/api/`、路由入口、全局样式和浏览器测试配置不允许并行修改。任务完成后必须先有主审核批准和关闭记录，后续任务才能启用。

## 4. 集成、发布、回滚与未验证事项

- 前端静态资源独立构建；FastAPI 只保留 API。生产同域反代、HTTPS、缓存和部署属于 `v1.5.0`，本版本不实现或验证生产环境发布。
- 本地开发与浏览器测试通过 Vite `/api` 代理指向显式本地地址；不得将服务器地址、密钥或真实用户数据写入仓库。
- 真实 API E2E 采用 T1 提供的临时 SQLite 发布库和既有公共路由 HTTP 服务，不导入 `app.main`，因而不启动 scheduler 或生产流水线；固定种子、时区和端口启动命令由 T1 锁定。
- 回滚边界为撤回 `frontend/` 新增资源，不触及已发布 API、内容库和消息流水线。
- 未验证项：真实生产反代、CDN 缓存和跨域 Cookie 不在本版本验收范围；隔离 E2E 服务验证实际公共路由与 SQLite 发布库，不替代生产验证。
- 本方案与任务包为草案，不能启用编码。用户批准网页路由、交互和视觉基线后，需将相关网站设计标为 `approved`、记录不可变 SHA，并更新本方案及任务包的设计基线。

## 5. 执行顺序

1. 冻结并批准《公共网站前端设计》。
2. 将本方案和 T1-T4 从 `draft` 完善为 `ready`，以批准设计 SHA 替换暂定基线。
3. 每项任务经独立启动审查后进入 `active`，运行 `make task-gate`，测试先行实现。
4. 每项实现经过主审核、任务提交与关闭记录，再启动其依赖任务。
5. T4 完成构建、类型检查、单元测试、端到端测试和公共边界检查；T5 同步正式版本元数据并完成发布前检查。用户另行批准后才可合并、推送、创建 tag 或部署。
