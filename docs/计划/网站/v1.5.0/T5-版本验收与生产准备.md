## 1. 背景

局部任务完成不证明部署、恢复、隔离演练和维护目标可共同支撑首次生产验收。

## 2. 目标

汇总设计退出条件、自动化检查、人工演练证据和未验证项，形成上线准备结论。

## 3. 前置依赖

T1-T4 全部通过审核；生产部署操作本身仍需用户明确批准。

## 4. 输入与输出契约

输入为 T1-T4 提交、检查结果和验收环境证据；输出为可追溯验收记录和遗留项。不得将未执行的生产步骤标为通过。

## 5. 修改范围

只汇总验收证据、文档入口、文档状态与待办，不修改业务或部署实现。

## 6. 禁止事项

不得执行生产部署、推送、合并、tag 或破坏性恢复；不得删改失败证据。

## 7. 执行要求

逐条映射设计退出条件；隔离测试须覆盖生产变体拒绝、失败无外溢、两次状态序列和生产状态不变；人工证据写明环境和时间。

## 8. 实施步骤

1. 汇总 T1-T4 证据和设计映射。
2. 运行精确与完整质量检查。
3. 汇总 T2-T4 的正式文档入口，并复核部署记录、回滚、维护和未验证项。

## 9. 验收标准

每项设计目标有自动化或人工证据；未验证项有编号、关闭条件和阻塞说明；完整质量检查通过。

## 10. 检查命令

```bash
make test
make lint
./venv/bin/ruff format --check .
make check-public
```

## 11. 交付前自检

核对退出条件、真实渠道证据、生产状态隔离和未验证项；未执行生产操作。

## 12. 交付格式

按固定格式，重点说明上线前证据、遗留风险和需用户批准的生产步骤。
