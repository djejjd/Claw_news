## 1. 背景

公共新闻流展示最近十天的已发布文章，来源筛选必须使用稳定来源名并与服务端分页一起工作，不能从当前页面内容本地猜测总量。

## 2. 目标

交付新闻流页面、来源选择、服务端分页、文章原文跳转和对应的加载、空、失败状态。

## 3. 前置依赖

- T2 已完成并经审核；
- 《公共网站前端设计》第 3-5 节已批准并冻结；
- `/api/public/articles` 的 `page`、`page_size`、`source` 和分页 DTO，以及 `/api/public/sources` 的排序与公开字段保持不变。

## 4. 输入与输出契约

输入为 `ArticlePage`、`SourcePublic[]` 和统一错误 DTO。输出为最近十天新闻流：来源筛选值直接作为 `source` 参数；切换来源后页码重置为 `1`；本版本不提供日期筛选；超末页的空 `items` 显示空结果而不是错误；非法请求或服务故障显示失败状态。文章显示标题、来源、分类、时间、可选主题和来源摘要，原文只链接到 `original_url`。

## 5. 修改范围与接口变更表

| 变更 | 输入/返回 | 副作用 | 兼容性 | 测试 |
|---|---|---|---|---|
| 新增新闻流页 | `ArticlePage` -> 列表与分页 | GET 请求 | 不改变后端排序 | 翻页、超末页、错误 |
| 新增来源筛选 | `SourcePublic[]`、稳定 `name` -> 查询参数 | GET 请求 | 不传内部 feed 字段 | 筛选、重置、未知来源空结果 |
| 新增文章外链 | `original_url` -> 新窗口跳转 | 无 | 不抓取正文 | URL、空摘要、窄屏 |
| 保持 API | 参数/DTO/错误不变 | 无 | 完全保持 | fixture 契约测试 |

| 接口 | 参数与 URL 同步 | 成功输出 | 错误与页面语义 | 兼容性与测试 |
|---|---|---|---|---|
| `GET /api/public/articles` | 默认不传 `source`、`page`；来源使用 `source=<稳定 name>`；页码仅发送正整数 `page`。切换来源写入 `source` 并删除 `page`；翻页只更新 `page`。非法 URL 参数归一为默认值，且不发送非法页码。 | `ArticlePage`，保持 API 返回顺序、`page`、`page_size`、`total`。 | `422/invalid_request`、`503/publication_unavailable`、网络或未知响应显示可重试失败；未知来源和超末页的空 `items` 显示空结果。 | 不改变 API 查询、DTO 或排序；组件和浏览器测试覆盖默认、两次筛选/分页变化、空结果、422/503、网络失败。 |
| `GET /api/public/sources` | 无参数；加载筛选项时不向 URL 写入内部字段。 | `SourcePublic[]`，只使用 `name`、`display_name`、`site_url`。 | `503`、网络或未知响应显示可重试失败，不把旧来源或文章伪装为当前结果。 | 不改变来源排序或公开字段；组件和浏览器测试覆盖成功、503、网络失败。 |

## 6. 禁止事项

- 不实现客户端全文搜索、无限滚动、推荐、订阅或已读状态；
- 不在客户端重排、合并或补造文章；
- 不将来源 feed、健康、评分或其他内部字段传入 URL 或显示；
- 不修改后端 API、日报语义或前端工程配置。

## 7. 执行要求

先用失败测试固定服务端分页、筛选重置、空列表、网络故障和外链行为。筛选与分页转换期间不得显示错误来源的旧结果；任何异步竞态处理须使用中文注释说明为什么丢弃旧响应。

## 8. 实施步骤

1. 添加文章页、来源列表、筛选和分页的失败测试。
2. 添加正常、空结果、超末页、503、网络失败与快速切换来源的反向测试。
3. 实现查询参数、页面状态、文章列表与外链。
4. 执行单元、浏览器、类型和构建检查，提交主审核。

## 9. 验收标准

1. 新闻流只由公共 articles API 驱动，默认覆盖服务端定义的十天窗口。
2. 来源筛选使用稳定 `name`，切换筛选后重置页码且结果与 API 相符。
3. 翻页无客户端重复或漏项；超末页和未知来源显示可理解的空状态。
4. 成功、加载、空、503 与网络失败状态明确；原文跳转正确，移动端可读。

## 10. 检查命令

运行前端类型检查、新闻流和来源组件单元测试、筛选分页浏览器测试、前端构建和 `make check-public`。

## 11. 交付前自检

确认只修改允许路径；测试覆盖两次以上筛选/分页变化序列、正常/边界/失败及反向竞态；无 mock fallback、内部字段或写操作；已审核 diff。

按仓库固定交付格式列出完成内容、文件、契约对应、检查结果、测试、未完成项、风险、冲突、范围外改动和主审核重点。
