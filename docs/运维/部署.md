# 服务器部署

生产环境使用 Docker Compose。`deploy-prod.sh` 由本地执行，通过 `rsync` 同步代码到服务器；`.env` 和 `data/` 不随代码同步。

```bash
make lint
make test
bash deploy-prod.sh
```

脚本会在服务器构建镜像、重启服务并检查 `/health`。启动检查只强制三个 LLM 配置；要成功发布还需至少配置一个推送渠道。

`.env` 示例：

```dotenv
LLM_API_KEY=真实密钥
LLM_BASE_URL=https://api.example.com/v1
LLM_MODEL=模型名称
FEISHU_APP_ID=可选
FEISHU_APP_SECRET=可选
FEISHU_CHAT_ID=可选
TELEGRAM_BOT_TOKEN=可选
TELEGRAM_CHAT_ID=可选
WECOM_WEBHOOK_URL=可选
```

飞书三个参数必须一起填写，Telegram 的 token 和 chat ID 也必须一起填写。`.env` 权限应为 `600`。

如果服务器访问 GitHub 不稳定，不要把服务器 `git pull` 作为主要路径；直接在本地执行 `deploy-prod.sh`。部署完成后按 [运行与验证](运行.md) 检查服务和实际推送。
