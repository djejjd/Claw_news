# 服务器部署

生产环境使用 Docker Compose。公开仓库不保存服务器地址、账号或私有发布脚本；可基于 `deploy.example.sh` 在本地维护部署入口。同步代码时不要包含 `.env` 和 `data/`。

```bash
make lint
make test
docker compose up -d --build
```

部署后检查 `/health`。启动检查只强制三个 LLM 配置；要成功发布还需至少配置一个推送渠道。

`.env` 示例：

```dotenv
LLM_API_KEY=真实密钥
LLM_BASE_URL=https://api.example.com/v1
LLM_MODEL=模型名称
FEISHU_APP_ID=可选
FEISHU_APP_SECRET=可选
FEISHU_CHAT_ID=可选
TELEGRAM_BOT_TOKEN=可选
TELEGRAM_CHAT_ID=可选
WECOM_WEBHOOK_URL=可选
```

飞书三个参数必须一起填写，Telegram 的 token 和 chat ID 也必须一起填写。`.env` 权限应为 `600`。

如果服务器访问 GitHub 不稳定，不要把服务器 `git pull` 作为主要路径；在本地通过私有脚本或 CI 同步构建产物。部署完成后按 [运行与验证](运行.md) 检查服务和实际推送。
