## 没有收到推送

先看：

```bash
cat data/publish_status.json | python3 -m json.tool
curl -sS http://127.0.0.1:8000/health | python3 -m json.tool
```

`failed` 重点看 `errors` 和渠道状态；`skipped` 通常表示候选为空或已被跨次去重；配置渠道为空时不会发送。

## 条数少或来源单一

检查最新 `ai_digest.json` 和候选池，再用内容回放查看 `source_distribution`、`category_distribution`、`backfill_count` 和拒绝原因。IT之家、TapTap 单次最多 3 条，候选不足时无法凭空补足。

## API key 或配置错误

确认服务目录存在 `.env`，变量名与 `.env.example` 一致，文件权限为 `600`，并运行：

```bash
make check-config
```

进程环境变量会覆盖 `.env`；修改后需重启容器或服务。

## 服务异常

```bash
docker logs claw-news --tail 50
```

区分来源失败、LLM 请求失败和渠道推送失败。单个来源失败不应阻断其他来源，但所有必需配置缺失会阻止服务启动。
