## 推荐流程

生产环境使用 Docker Compose。当前 `deploy-prod.sh` 从本地工作区同步代码到服务器，`.env` 和 `data/` 不随代码同步。

```bash
make lint
make test
bash deploy-prod.sh
```

脚本会同步代码、构建镜像、重启服务并检查 `/health`。启动检查只强制 LLM 三项；要成功发布还必须配置至少一个推送渠道。

## 配置要求

```dotenv
LLM_API_KEY=真实密钥
LLM_BASE_URL=https://api.example.com/v1
LLM_MODEL=模型名称
FEISHU_APP_ID=可选
FEISHU_APP_SECRET=可选
FEISHU_CHAT_ID=可选
```

飞书三个参数必须一起填写；Telegram 的 token 和 chat ID 必须一起填写。`.env` 权限应为 `600`。

## 发布后

部署完成后按 [发版后验证](发版后验证.md) 检查容器、健康状态、手动触发和实际推送。
