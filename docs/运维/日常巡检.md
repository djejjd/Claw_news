## 服务和来源

```bash
curl -sS http://127.0.0.1:8000/health | python3 -m json.tool
```

重点看 `status`、`ingest_fresh`、`last_publish` 和 `sources`。`failed` 需要排查，`degraded` 先确认是否为可选来源。

## 内容

查看最新 `ai_digest.json`，确认总条数接近 10 条，AI、工具、游戏没有长期缺失，单个高频来源没有占据大多数。

需要复核选材时使用只读回放：

```bash
./venv/bin/python scripts/replay-content-selection.py \
  --data-dir data --at '<检查时间，含时区>' --format json
```

不要提交生产 `data/`、候选原文、运行时 feeds 或任何凭据。
