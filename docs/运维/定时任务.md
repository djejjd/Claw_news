## 服务模式

正式服务内置 APScheduler：每天 09:00 执行一次发布任务，每 30 分钟刷新候选池，时间使用 `TZ` 配置，默认 `Asia/Shanghai`。

服务必须保持单实例运行。不要同时启用容器内调度和外部 cron 发布，否则可能重复推送。

## macOS launchd

launchd 仅用于本地或旧 CLI 兼容方案。生产服务使用 APScheduler 时，不要同时加载 launchd，否则可能重复或产生不同时间的推送。仓库保留 launchd 示例模板，使用前复制并把 `{{PROJECT_DIR}}` 替换为本机项目路径：

```bash
cp docs/运维/launchd/com.lanser.clawnews.morning.plist.example \
  ~/Library/LaunchAgents/com.lanser.clawnews.morning.plist
cp docs/运维/launchd/com.lanser.clawnews.evening.plist.example \
  ~/Library/LaunchAgents/com.lanser.clawnews.evening.plist
```

launchd 不读取交互式 shell 环境变量，项目根目录 `.env` 是唯一运行配置文件。
