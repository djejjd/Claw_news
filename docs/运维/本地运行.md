## 安装

```bash
make install
cp .env.example .env
```

编辑 `.env`。启动检查只要求 `LLM_API_KEY`、`LLM_BASE_URL` 和 `LLM_MODEL`；要执行实际发布，还需至少配置一个可用推送渠道。各渠道参数必须成组填写。

## 检查和测试

```bash
make check-config
make test
make dry-run
```

`dry-run` 不触发真实 LLM 摘要和推送。正式服务使用：

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

启动后可访问 `GET /health`，手动发布使用 `POST /run/news`。
