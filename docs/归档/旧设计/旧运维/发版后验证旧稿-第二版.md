## 检查顺序

```bash
docker ps --format '{{.Names}} {{.Status}}' | grep claw-news
curl -sS http://127.0.0.1:8000/health | python3 -m json.tool
curl -sS -X POST http://127.0.0.1:8000/run/news | python3 -m json.tool
```

确认容器持续运行，`health.status` 为 `healthy` 或 `degraded`。刚部署时可先等待一次候选采集，或手动触发采集后再要求 `ingest_fresh` 为 `true`；手动发布结果不应为 `failed`。

## 内容检查

查看 `data/` 中最新摘要，确认新闻条数、分类分布、来源分布和原文链接。来源指标写入异常会出现在 `errors` 中，它不等同于推送失败，但应记录到 [待办](../计划/待办.md)。
