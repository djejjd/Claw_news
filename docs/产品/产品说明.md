## 用途

Claw_news 定时收集 AI、工具、游戏和数码领域的公开资讯，经规则选材和 LLM 摘要后推送到已配置的消息渠道。

## 用户得到什么

- 每次摘要尽量提供 10 条新闻。
- AI、工具、游戏按候选情况进行分类保底。
- 新闻保留原文链接，并显示来源。
- IT之家、TapTap 等高频来源单次最多进入 3 条，候选不足时用较新的历史候选补位。
- 可配置飞书、企业微信和 Telegram；未配置的渠道不会发送。

## 运行方式

正式入口是 FastAPI 服务。服务内的 APScheduler 定时刷新候选池并执行发布任务；`main.py` 仅保留兼容 CLI 和本地 dry-run。

## 不负责什么

项目不保证所有来源每次可用，不抓取需要登录的内容，也不把 LLM 输出当作事实来源。原文链接和来源信息用于人工复核。
